# Quantenkryptografie (Lernlabor)

Digitale Werkzeuge zum Lernlabor Quantenkryptografie, veröffentlicht mit GitHub Pages unter
https://discoverylabs-uibk.github.io/quantumcrypto/

| Ordner | Inhalt |
|---|---|
| `/` | Übersichtsseite des Labors |
| `rsa-rechner/` | RSA-Rechner für die Station Asymmetrische Verschlüsselung (d finden, verschlüsseln, entschlüsseln) |

Jede Seite ist eine einzelne HTML-Datei ohne externe Bibliotheken. Die Rechnungen laufen vollständig im Browser.

Neues Werkzeug hinzufügen: Ordner mit `index.html` anlegen und auf der Übersichtsseite eine Karte verlinken.
Nur Inhalte ablegen, die öffentlich sein dürfen.
